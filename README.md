**Hi!【隔壁】帮你打破距离，也帮你保持距离。**

---

专为年轻人合租场景设计的 Web 管理平台，用轻量、可操作的界面解决「钱怎么分、地谁扫、东西谁买、规则怎么定」等高频矛盾点。当前版本为前端静态站点，业务数据保存在浏览器本地（localStorage），适合演示与个人试用。

---

## 已上线功能

### 首页

| 功能 | 介绍 |
|------|------|
| 品牌标语 | 首页展示「隔壁」标题及 Slogan：「Hi!【隔壁】帮你打破距离，也帮你保持距离。」 |
| 入组仪表盘 | 展示所属合租集体、入组天数与四大模块入口卡片。 |
| 景区留言板 | 默认标题「AAAA景区留言板」，名称可编辑保存；支持发布留言，列表展示作者与时间（本地持久化）。 |

### 费用 AA 分摊（`/expenses`）

| 功能 | 介绍 |
|------|------|
| 账单列表与汇总 | 展示本月总支出、参考人均、待结算笔数及全部账单。 |
| 新增账单 | 录入名称、类型、总额、日期，并在同一页选择 **均分 AA / 按金额 / 按比例** 分摊后提交。 |
| 账单详情 | 查看分摊明细；滑动开关标记各室友 **已付款 / 待付款**，全员已付后自动变为「已结清」。 |
| 编辑账单 | 详情页右上角「编辑」可修改 **账单名称** 与 **分摊方式**（保留已记录的付款状态）。 |

### 清洁值日排班（`/cleaning`）

| 功能 | 介绍 |
|------|------|
| 今日值日与本周排班 | 展示当日负责人、区域及整周排班状态（进行中 / 已完成）。 |
| 调整排班 | 拖拽清洁区域至各室友列，确认后更新本周轮换逻辑（周一至周五按人轮换，周六大扫除，周日休息）。 |
| 值日打卡 | 上传清洁完成照片（自动压缩），确认打卡后更新排班与首页「已打卡」状态。 |

### 公共物品登记（`/items`）

| 功能 | 介绍 |
|------|------|
| 物品清单 | 展示在库数量、需补货数量、本月消耗次数及库存状态（充足 / 需补货 / 已用完）。 |
| 登记物品 | 新增公共消耗品，设置初始库存与预警阈值。 |
| 记录消耗 | 选择物品与使用人，扣减库存并写入消耗记录。 |
| 编辑物品 | 从清单进入详情并进入编辑模式，可改名称、单位、余量与阈值。 |

### 室友公约管理（`/agreement`）

| 功能 | 介绍 |
|------|------|
| 公约列表与签署概览 | 展示全部条款、同意人数、签署进度与最近更新时间。 |
| 新增条款 | 添加分类与内容，新条款进入「待表决」状态并重置签署状态。 |
| 编辑条款 | 选择已有条款修改内容，保存后室友需重新签署。 |
| 发起投票 | 对待表决条款投赞成票（可切换室友身份），达到人数后条款生效。 |
| 签署公约 | 阅读摘要并勾选确认，完成当前账号（或所选室友）的公约签署。 |

### 其他页面

| 功能 | 介绍 |
|------|------|
| 合租房设置（`/room/settings`） | 只读展示集体名称、邀请码、成员列表与入组信息。 |
| 个人中心（`/profile`） | 展示昵称、头像、手机号与入组信息；右上角 **编辑** 可修改资料并保存至本地（新留言与消耗记录会使用更新后的昵称）。 |

## 构建与部署

项目通过 GitHub Actions 自动构建并发布到 GitHub Pages。推送 `main` 分支后会自动部署。


### 首次启用 GitHub Pages

1. 推送代码到 `main` 分支，等待 **Actions** 工作流完成（会将 `dist/` 发布到 `gh-pages` 分支）
2. 打开仓库 **Settings → Pages**
3. **Build and deployment → Source** 选择 **Deploy from a branch**
4. **Branch** 选择 `gh-pages`，文件夹选 `/ (root)`，点击 **Save**

> 若页面空白，通常是 Pages 仍指向 `main` 分支根目录。务必切换到 `gh-pages` 分支。
